# 🚀 Recruitment Orchestrator (AI-Powered JD Parser)

An AI-driven recruitment automation tool that transforms unstructured Job Descriptions into structured, actionable hiring intelligence.

---

## 🧠 Problem Statement

Recruiters spend hours manually analyzing Job Descriptions (JDs) to extract:
- Role requirements
- Skills and experience
- Rate expectations
- Visa/work authorization constraints

This process is:
- Time-consuming
- Error-prone
- Inconsistent across recruiters

---

## 💡 Solution

Recruitment Orchestrator uses AI (Claude Sonnet) to:

✅ Parse raw JDs into structured data  
✅ Extract key hiring signals (skills, role, experience)  
✅ Identify missing/ambiguous requirements  
✅ Standardize recruiter decision-making  

---

## ⚙️ Key Features

- 🔍 JD Parsing Engine
  - Extracts role title, skills, experience
  - Detects rate info and constraints

- 🧠 AI-Powered Analysis
  - Uses LLMs for contextual understanding
  - Flags ambiguity (no assumptions)

- 📊 Structured Output
  - Clean JSON-style output for downstream use

- 🚫 Strict Parsing Logic
  - No hallucination policy
  - Explicit-only extraction

---

## 🧩 Tech Stack

- Frontend: React (JSX)
- Runtime: Node.js
- AI Layer: Claude Sonnet (LLM)
- Future: API + Automation Agents
